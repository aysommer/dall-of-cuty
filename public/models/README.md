# Модели

`xbot.glb` — безликий манекен **X Bot** с сайта [Mixamo](https://www.mixamo.com) (Adobe): модель со скелетом и анимациями
`idle`, `walk`, `run`. Файл взят из примеров three.js
(`examples/models/gltf/Xbot.glb` в репозитории [mrdoob/three.js](https://github.com/mrdoob/three.js)).

Mixamo разрешает бесплатно использовать своих персонажей и анимации в играх и других проектах, в том числе коммерческих,
но не разрешает распространять их отдельно как набор моделей. Если проект будет публиковаться шире, чем игра,
проверьте актуальные условия Adobe или замените модель: код ждёт скелет с костями Mixamo (`mixamorig:Hips`, `…Spine`, `…LeftArm` и т. д.)
и клипы `idle`, `walk`, `run` — подойдёт любой персонаж Mixamo.
