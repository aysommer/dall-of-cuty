# Dall of Cuty

Простой сетевой 3D-шутер из кубиков на HTML, CSS и TypeScript: клиент на Three.js, сервер на Node.js, связь по WebSocket.

- До 4 игроков на сервере.
- Режимы: **команды 2 × 2** (зелёные против красных) или **каждый сам за себя**.
- Все игроки — одинаковые прямоугольники зелёного или красного цвета.
- У игрока с наибольшим числом убийств на голове корона; при ничьей короны нет ни у кого.
- Оружие: пистолет, дробовик, автомат, пулемёт, снайперская винтовка и нож — всё собрано из блоков.
  - В бой берёшь не больше двух стволов, нож есть всегда. Набор выбирается в меню (Esc), раздел «Оружие»: клавиша 2 — первый ствол, 3 — второй.
  - Патроны ограничены: пистолет — 3 магазина (36), дробовик — 24, автомат — 3 магазина (90), пулемёт — лента на 100, снайперка — 24. На экране — «в магазине / в запасе». После смерти запас полный.
  - С погибших падают патроны (лежат 30 секунд): подобрав, получаешь половину полного запаса к обоим своим стволам.
  - Стрельба от бедра в два раза менее точная, чем в прицел (ПКМ). Даже в прицеле небольшой разброс остаётся.
  - Урон по зонам: голова — верх стоящего прямоугольника. В голову урон ×1,5; у снайперки попадание в голову убивает сразу (даже сквозь броню), в тело — 80 урона.
  - Автомат: 21 урона за пулю. Снайперка: в прицеле — снайперская оптика, от бедра — без прицела; после каждого выстрела передёргивается затвор. Нож: убивает с одного удара вплотную (до 2 м), удар — горизонтальный взмах. Нож можно бросить (G или ПКМ с ножом в руке): 50 урона, летит почти прямо, попадание видно по маркеру; после броска ножа нет до следующей жизни.
  - Пулемёт: лента на 100 патронов, отдача вдвое сильнее, чем у автомата, долгая перезарядка.
  - У пистолета, дробовика и автомата коллиматорный прицел: при прицеливании (ПКМ) красная точка встаёт в центр экрана.
  - У каждого оружия своя анимация перезарядки: магазин вынимается и вставляется, у дробовика по очереди вставляются патроны.
  - Отдача поднимает прицел только на мгновение, потом он возвращается на место.
- Шаги других игроков слышно: чем ближе игрок, тем громче, и звук идёт с его стороны.
- На каждой карте есть канализация: два люка с лестницами (как на башне — W/S по взгляду, прыжок — спрыгнуть) и коридор под землёй между ними. Под землёй темно (стены из тёмного бетона), посередине коридора горит фонарь; из люка снизу видно улицу. Люки шириной 2 м.
- У каждого игрока на модели пиксельное лицо: чем больше у него убийств в матче, тем оно злее — пять ступеней, от спокойного до свирепого (на последней — красные глаза). Своё лицо видно рядом с HP.
- Звания: каждые 50 убийств (за всё время) — следующее звание армии США, от рядового (PV1) до генерала армии (GA). Звание видно в таблице по Tab рядом с именем и в меню Esc.
- Погода: раз в 3 минуты с вероятностью 25% на минуту начинается дождь или снег — видимость падает.
- Раз в 60 секунд с неба падает аптечка (не больше трёх на карте). Подойди к ней, если здоровье не полное, — она вылечит на 50 HP, но не выше 100. Не подобранная аптечка исчезает через 15 секунд после приземления (последние 3 секунды мигает).
- Погибший прямоугольник падает на спину, а через секунду уходит под землю.
- Две карты на выбор (карту, как и режим, выбирает первый зашедший игрок):
  - **Пески** — две базы и три линии: открытая «длина», центр с дверями, крытый туннель. Арена 60 × 60 м.
  - **Кубики** — компактная снайперская арена из цветных блоков: базы на помостах друг напротив друга и башня в центре, на которую ведут две лестницы.
  - **Склад** — маленькая арена для ближнего боя: базы за перегородками, контейнеры и мост поперёк карты с лестницами на обоих концах.

## Запуск в Docker

```bash
docker compose up -d --build
```

Или без Compose:

```bash
docker build -t dall-of-cuty .
docker run -d -p 3000:3000 -v dall-of-cuty-data:/app/data --name dall-of-cuty dall-of-cuty
```

Открой `http://localhost:3000`. Друзья в той же сети заходят по адресу `http://<IP-компьютера>:3000`.
Внешний порт для Compose меняется переменной `PORT`, например `PORT=8080 docker compose up -d`.

## Запуск без Docker

Нужен Node.js 20 или новее.

```bash
npm install
npm run build
npm start
```

`npm run typecheck` — только проверка типов.

Появление: сервер ставит игрока в точку, которую в этот момент не видит ни один противник (в командном режиме — сначала на своей базе). Если таких точек нет, выбирается та, которую видит меньше всего противников.

Режим, карту и ограничение матча выбирает первый зашедший игрок: либо по времени (5, 10 или 15 минут), либо по убийствам (50, 100 или 150 — убийств команды в 2 × 2 или одного игрока в «каждый сам за себя»). Потом 15 секунд все голосуют за следующую карту; при равенстве голосов (или если никто не голосовал) карта выбирается случайно из лидеров.

## Серия убийств

Награды за убийства подряд без смерти. Счётчик серии — слева над HP.

| Серия | Награда |
| --- | --- |
| 3 | БПЛА (клавиша 5): 30 секунд на мини-карте видны противники, отметки обновляются каждые 2 секунды импульсом эхо-локации. В командах их видит вся команда |
| 4 | Ракета с неба (клавиша 6): управляешь ей от первого лица мышью, ЛКМ — ускорение. Взрыв убивает в радиусе 6 м — и тебя, если ты рядом. После взрыва ракета сразу исчезает |
| 5 | Ракетница (клавиша 7): 6 ракет |
| 7 | Джаггернаут: суперброня 500 единиц, игрок в полтора раза больше, пока броня не кончится, и шлем — выстрелы в голову урона не наносят, пока шлем не собьют тремя попаданиями |
| 15 | Бомба (клавиша 8): падает с неба через 4 секунды, вспышка на весь экран, погибают все на карте |

БПЛА, ракету с неба и бомбу можно применить и после смерти — они лежат в запасе, пока их не используют. Убийства бомбой серию не продолжают.

## Управление

| Клавиша | Действие |
| --- | --- |
| W A S D | движение |
| Shift | спринт (в прицеле не работает) |
| C в спринте | подкат: игрок ложится и 1 секунду скользит по инерции |
| Пробел | прыжок (можно запрыгивать на ящики) |
| W / S у лестницы | лезть вверх / вниз (W ведёт вниз, если смотреть вниз или от лестницы); прыжок — спрыгнуть |
| Мышь | обзор; ЛКМ — огонь, ПКМ (зажать) — прицел (с ножом в руке — бросок) |
| 1 / 2 / 3, колесо | нож / первый ствол набора / второй ствол набора |
| 5 / 6 / 7 / 8 | награды за серию: БПЛА / ракета с неба / ракетница / бомба |
| G | бросить нож |
| R | перезарядка |
| F | открыть ящик с ракетницей; повторно — отменить |
| T | нарисовать на стене случайный эмодзи из ста (видят все, держится минуту; не чаще раза в минуту) |
| Tab | таблица счёта |
| Esc | меню: настройки и прокачка; повторное Esc закрывает меню и сразу возвращает в игру (если браузер не вернул мышь сам, первый клик вернёт её, не стреляя) |

## Ящик с ракетницей

Раз в минуту с вероятностью 50% на карту с неба падает ящик с надписью «Open me 😈». Точка падения выбирается случайно из нескольких открытых мест карты (на «Кубиках» — в том числе вершина башни, на «Складе» — мост). Над лежащим ящиком горит столб света.

- Упавший ящик лежит 2 минуты. Если его никто не открыл, он исчезает (последние 10 секунд мигает). Пока ящик лежит на карте, новый не падает.

- Открывается 1 секунду по нажатию F. Двигаться, прыгать и стрелять в это время нельзя.
- Повторное нажатие F, смерть или любое смещение отменяют открытие, и прогресс сбрасывается.
- Внутри одно из трёх: 10% — ловушка (взрыв), 40% — ракетница, 50% — броня.
- Броня даёт ещё 100 единиц: урон сначала снимает броню, потом здоровье. Игрок в броне носит жилет — он закрывает корпус, голова и ноги видны. Броня кончилась — жилет пропадает; после смерти брони нет.
- Ракетница: 6 ракет, без перезарядки. Ракета убивает с первого раза всех противников в радиусе 4 м от взрыва; стена от взрыва закрывает. Стрелок тоже погибает, если сам оказался в этом радиусе (убийство ему не засчитывается). Союзников взрыв не задевает.
- Ловушка: ящик взрывается и убивает всех в радиусе 5 м — открывшего, союзников и противников. Стена закрывает и от этого взрыва. Такие смерти никому не засчитываются как убийства.
- Ракетница пропадает, когда кончаются ракеты или владелец погибает. С началом нового раунда ящик убирается, а расписание сбросов продолжается.

Сброс, открытие, полёт ракет и взрывы считает сервер.

## Настройки

В меню входа и в меню по Esc: громкость звука, чувствительность мыши, оружие справа или слева (по умолчанию справа). Настройки хранятся в браузере.

## Прокачка

За каждые 10 убийств даётся 1 очко. Улучшений три, у каждого три ступени:

| Улучшение | Ступени |
| --- | --- |
| Спринт (множитель скорости с Shift) | ×1.25 → ×1.30 → ×1.35 → ×1.40 |
| Ходьба (скорость) | ×1.00 → ×1.05 → ×1.10 → ×1.15 |
| Перезарядка (скорость) | ×1.00 → ×1.03 → ×1.06 → ×1.10 |

Прогресс лежит в `localStorage` браузера в виде токена, зашифрованного ключом сервера (AES-256-GCM). Убийства считает и токен выдаёт только сервер, поэтому в браузере прогресс нельзя ни прочитать, ни подделать: изменённый токен сервер отвергает, и прогресс начинается с нуля.

Ключ сервер берёт из переменной окружения `PROGRESS_SECRET`, а если её нет — создаёт сам и хранит в `data/secret.key` (в Docker это том `game-data`). Если ключ потерять или сменить, прогресс всех игроков обнулится.

## Структура

Весь код — на TypeScript; сервер работает на Node.js.

- `src/server/index.ts` — раздача статики и игровая комната: здоровье, урон, счёт, возрождение.
- `src/client/game.ts` — рендер (Three.js), управление, стрельба, сеть, интерфейс.
- `src/shared/map.ts` — список карт, параметры оружия и лучи; общий модуль клиента и сервера.
- `src/shared/maps/` — сами карты (`sands.ts`, `bricks.ts`, `depot.ts`) и их типы. Новая карта — новый файл плюс строка в `MAPS`.
- `src/server/spawn.ts` — выбор точки появления вне поля зрения противников.
- `src/server/progress.ts` — шифрование и проверка токена прогресса.
- `src/shared/progress.ts` — правила прокачки.
- `src/shared/protocol.ts` — типы сетевых сообщений.
- `public/` — HTML и CSS.
- `Dockerfile`, `docker-compose.yml` — сборка и запуск контейнера.

Сборка кладёт всё в `dist/`: сервер компилирует `tsc`, клиент собирает в один файл `esbuild`.
