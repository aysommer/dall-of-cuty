# Dall of Cuty

Простой сетевой 3D-шутер из кубиков на HTML, CSS и JavaScript (Three.js + WebSocket).

- До 4 игроков на сервере.
- Режимы: **команды 2 × 2** (зелёные против красных) или **каждый сам за себя**.
- Все игроки — одинаковые прямоугольники зелёного или красного цвета.
- Оружие: пистолет, дробовик, винтовка — всё собрано из блоков.
- Карта в духе классических «песчаных» арен: две базы и три линии (открытая «длина», центр с дверями, крытый туннель).

## Запуск

```bash
npm install
npm start
```

Открой `http://localhost:3000`. Друзья в той же сети заходят по адресу `http://<IP-компьютера>:3000`.
Порт меняется переменной окружения `PORT`.

Режим выбирает первый зашедший игрок. Раунд идёт до 20 убийств команды (2 × 2) или до 15 убийств игрока (каждый сам за себя), затем начинается заново.

## Управление

| Клавиша | Действие |
| --- | --- |
| W A S D | движение |
| Пробел | прыжок (можно запрыгивать на ящики) |
| Мышь | прицел, ЛКМ — огонь |
| 1 / 2 / 3, колесо | пистолет / дробовик / винтовка |
| R | перезарядка |
| Tab | таблица счёта |

## Структура

- `server.js` — раздача статики и игровая комната: здоровье, урон, счёт, возрождение.
- `public/shared/map.js` — карта, параметры оружия и лучи; используется и клиентом, и сервером.
- `public/game.js` — рендер, управление, стрельба, сеть, интерфейс.
